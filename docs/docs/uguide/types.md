# Types

:book: This page describes the `invoke_tasklib.types` module.

## Overview

| Task          | Behavior                                                                           |
| ------------- | ---------------------------------------------------------------------------------- |
| `types.check` | Checks type hints with [ty](https://docs.astral.sh/ty/) (read-only) |

## Usage

```shell
invoke types.check
```

This runs `ty check`.
