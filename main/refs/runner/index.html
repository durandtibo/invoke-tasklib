    invoke_tasklib.runner.build_command ¶

    build_command(
    program: str,
    *,
    args: str | None = None,
    paths: str | None = None,
    default_paths: Sequence[str] = (),
    args_option: str = "--args",
) -> str

    Build a command line from a program and the options of a task.

    Parameters:

    Name Type Description Default
    program str

    The program and its fixed arguments, e.g. "ruff check". It is used as it is (not quoted).

    		 required
    args str | None

    Extra arguments of the user, as one string that is split like a shell does, e.g. "-k foo -x". They come after the fixed arguments.

    		 None
    paths str | None

    Paths of the user, as one string that is split like a shell does. They replace default_paths. A glob (*) or ~ is quoted, so the tool receives it as it is: it is up to the tool to expand a glob, and ~ is never expanded.

    		 None
    default_paths Sequence[str]

    The paths used when paths is not set.

    		 ()
    args_option str

    The name of the option that args comes from, used in the error message (for a task that has more than one set of arguments, e.g. "--pyright-args").

    		 '--args'

    Returns:

    Type Description
    str

    The command line. The arguments and the paths are quoted when
    str

    needed, so the shell does not expand a glob, ~ or $VAR.

    Raises:

    Type Description
    Exit

    If args or paths cannot be split (for example an unclosed quote).

    Example usage:

    >>> from invoke_tasklib.runner import build_command
>>> build_command("ruff check", default_paths=["."])
'ruff check .'
>>> build_command("ruff", args="-x", paths="src")
'ruff -x src'
>>> build_command("ruff", paths="*.py")
"ruff '*.py'"

    invoke_tasklib.runner.check_program ¶

    check_program(command: str) -> None

    Check that the programs of a command are available.

    Every command of a pipeline (a | b, a && b) is checked, and the command run by xargs, env, sudo, time or nice is checked instead of the wrapper. A program is not checked when it is a path (for example the running interpreter, see python_executable, or ~/bin/tool) or one of UNCHECKED_PROGRAMS (the shell builtins). The NAME=value words before a program are ignored, and so is a command that starts a subshell, a group, a substitution ((, {, $() or a reserved word of the shell (if, for, !, ...). For python -m <module> with the running interpreter, the module is checked, and so are the plugins of the pytest options (see PLUGIN_OPTIONS).

    Parameters:

    Name Type Description Default
    command str

    The command line.

    		 required

    Raises:

    Type Description
    Exit

    If a program (or the module) is not found. The message says how to install it, see PROGRAM_HINTS.

    Example usage:

    >>> from invoke_tasklib.runner import check_program
>>> check_program("find . -name '*.sh'")
>>> check_program("no-such-program --version")
Traceback (most recent call last):
    ...
invoke.exceptions.Exit: ...

    invoke_tasklib.runner.python_executable ¶

    python_executable() -> str

    Return the shell-quoted path of the running Python interpreter.

    Tasks that run Python code or a Python module use this interpreter instead of the python found on the PATH: the interpreter running Invoke is the one that has the project installed, and it works outside an activated virtual environment.

    Returns:

    Type Description
    str

    The path of sys.executable, quoted for the shell.

    Example usage:

    >>> import sys
>>> from invoke_tasklib.runner import python_executable
>>> python_executable() == sys.executable
True

    invoke_tasklib.runner.run ¶

    run(
    c: Context,
    command: str,
    *,
    check: bool = True,
    **kwargs: Any,
) -> Result

    Run a command, echoing it and using a pty only on a terminal.

    The program of the command must be on the PATH, see check_program. Pass check=False to skip that check when the caller knows better, for example for a command that is defined by a shell function or alias.

    All the tasks run their commands through this helper so that they behave alike:

    • the command line is echoed (echo=True) so that the user sees what is run, unless echo is passed explicitly;
    • a pseudo-terminal is used (pty=True) only if sys.stdout is a terminal or run.pty is set in the Invoke config. A pty keeps the colors of the tools but merges stderr into stdout and is not available everywhere (for example Windows or some CI sandboxes).

    Parameters:

    Name Type Description Default
    c Context

    The invoke context.

    		 required
    command str

    The command to run.

    		 required
    check bool

    If False, do not check that the program is available.

    		 True
    **kwargs Any

    Additional keyword arguments passed to c.run. They take precedence over the defaults of this helper.

    		 {}

    Returns:

    Type Description
    Result

    The result of c.run.

    Raises:

    Type Description
    Exit

    If check is True and the program of the command is not found.

    Example usage:

    >>> from invoke.config import Config
>>> from invoke.context import MockContext
>>> from invoke_tasklib.runner import run
>>> c = MockContext(config=Config(), run=True)
>>> _ = run(c, "ls")
>>> c.run.call_args.kwargs["echo"]
True
