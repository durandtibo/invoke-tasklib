    invoke_tasklib.tools.check_program ¶

    check_program(command: str) -> None

    Check that the program of a command is available.

    Only the first word of the command is checked, after the NAME=value words that set environment variables. It is not checked when it is a path (for example the running interpreter, see python_executable, or ~/bin/tool) or one of UNCHECKED_PROGRAMS (the shell builtins). For python -m <module> with the running interpreter, the module is checked, and so are the plugins of the pytest options (see PLUGIN_OPTIONS).

    The tasks run one program, so the rest of the command line is not parsed: a pipeline (a | b), a list (a && b), a subshell or a reserved word of the shell is not understood, and only its first word is looked up. To run such a command, pass check=False to run. A command that cannot be split like a shell does (an unclosed quote) is not checked: the shell reports it.

    invoke_tasklib.tools.tool_path ¶

    tool_path() -> str

    Return the PATH that the tasks use to find the programs.

    The directory of the running interpreter comes first: it is where uv sync installs the programs (ruff, ty, mkdocs, ...) of the virtual environment. Python modules are found with the running interpreter, so the programs of the same environment are found the same way, with no need to activate it. It also makes the task run the program of the environment, not another one that is earlier on the PATH.

    Returns:

    Type Description
    str

    The PATH of the process with the directory of
    str

    sys.executable added to the front.

    Example usage:

    >>> import os
>>> from pathlib import Path
>>> import sys
>>> from invoke_tasklib.tools import tool_path
>>> first = tool_path().split(os.pathsep)[0]
>>> first == str(Path(sys.executable).parent)
True
